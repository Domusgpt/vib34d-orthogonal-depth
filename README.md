## 🚀 Quick Start

### Local Development
```bash
# Clone the repository
git clone https://github.com/yourusername/vib34d-orthogonal-depth.git
cd vib34d-orthogonal-depth

# Serve locally (any HTTP server)
python -m http.server 8000
# or
npx http-server

# Open http://localhost:8000/25-orthogonal-depth-progression.html
```

### GitHub Pages Deployment
1. Fork this repository
2. Go to Settings > Pages
3. Select "Deploy from a branch"
4. Choose "main" branch and "/" root
5. Your deployment will be available at: `https://yourusername.github.io/vib34d-orthogonal-depth/`
